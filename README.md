依原網站功能重建的可部署版本，保留：

- 耗材名稱／編碼／位置搜尋
- 門診、病房、洗腎室、急診四分類
- 4:3 圖片卡片與 4:3 放大彈窗
- 每筆耗材 QR Code；掃描後直接進入圖片頁
- QR 圖片頁：4:3 圖片、入帳碼、回首頁、關閉頁面
- 管理者登入、新增／編輯／刪除耗材、圖片上傳或網址
- Netlify Blobs 持久化耗材資料與累積訪客數
- Mobao Manufacturing Co., Ltd. Logo 與版權資訊
- Version 1.0.0

## Netlify 部署前必要設定

此 GitHub 倉庫為公開倉庫，因此管理者密碼**不寫入原始碼**。請在 Netlify 專案設定 3 個環境變數：

- `ADMIN_USERNAME`：設為指定的管理者帳號
- `ADMIN_PASSWORD`：設為指定的管理者密碼
- `ADMIN_SESSION_SECRET`：任意 32 字元以上隨機字串

設定後重新 Deploy，即可使用指定帳密登入。
